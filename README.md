# GitHub-Demo: Moderne Softwareentwicklung im Browser

Willkommen! Dieses kleine Repository dient dazu, den typischen Ablauf
moderner Softwareentwicklung einmal komplett durchzuspielen – **ohne
Installation, nur im Browser**.

## Worum geht es?

Ihr lernt den vollständigen Kreislauf kennen:

1. **Branch** anlegen – eine eigene Arbeitskopie für eure Änderung
2. **Commit** – eine Änderung mit Begründung speichern
3. **Pull Request** – die Änderung zur Überprüfung vorschlagen
4. **Review** – jemand schaut drüber und gibt Feedback
5. **CI (Continuous Integration)** – automatische Tests laufen los
6. **Merge** – die geprüfte Änderung landet im Hauptzweig (`main`)

## Was steckt drin?

- `rechner.py` – ein paar absichtlich einfache Funktionen
- `test_rechner.py` – die zugehörigen automatischen Tests
- `.github/workflows/ci.yml` – die CI-Pipeline, die bei jedem Pull
  Request die Tests ausführt

> Der Code ist mit Absicht trivial. Im Mittelpunkt steht der
> **Arbeitsablauf**, nicht die Programmierung.

## Probiert es aus

Ändert eine Zeile in dieser README (z. B. fügt euren Namen in der
Liste unten hinzu), legt dafür einen neuen Branch an und öffnet einen
Pull Request. Beobachtet, was passiert!
